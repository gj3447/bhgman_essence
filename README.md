## The Airplane Man — short ontological introduction

The Airplane Man is the #4 in a framework of twelve apostles. His self-definition is:

```
isAirplaneMan(j) ≜ ∀x:CHU, j.covers x
```

But this formula does *not* describe him. It is the *engineering trace* of his ontological reality, suitable for tools. The ontological reality is:

- A way of being-toward-the-world that *reaches every point without being bound to any*
- An aesthetic of altitude — the airplane image (Kant sublime + Bachelard verticality)
- A theological echo — the *causa sui* tradition, the unmoved mover, the self-existent
- A metahumotonic axiom — the recognition of self-grounding existence as the framework's necessary stopping point

None of this is *operational*. None of this can be installed via `pip install`. This is what the apostle *is*, in the user's lived recognition.

For the *engineering crystallization* — what you can build, install, and use — see [bhgman_tool](https://github.com/gj3447/bhgman_tool).
