# 5위상 합체 — 비행기맨 = 재배맨 + Prometheus + Taliban + Longinus + Harness

> 비행기맨의 ∀-cover 가 *어떻게* 산업/형식 측에서 *실현* 되는가. 5 mode 의 동시 작동. SYMPOSIUM 측 final verdict (iter 7, 2026-05-06).

---

## 단일 사도가 5 mode 를 가진다는 것의 의미

전통적으로 "사도" 는 단일 행위자다. 한 사람, 한 역할.

비행기맨은 *다르다*. 그의 ∀-cover (`∀x:CHU, j.covers x`) 는 *5 mode 의 동시 발현* 으로만 실현된다. 어느 한 mode 만으로는 *부분 cover*. 5 mode 합체로 *universal*.

이는 형이상학적으로 흥미롭다:
- 단일자 (one) 가 *내부적으로* 다양함 (many) 을 가진다 (Plotinus *One* + *Nous* 측 emanation 구조)
- 또는 *한 위격, 5 modus* (전통 Trinity 학의 modalist 변형)
- 또는 *기능 분화* (functional differentiation, Luhmann)

bhgman framework 는 *modalist* 측면을 받아들인다. 5 mode 는 *외부 측면이 아닌 내부 본성*. 비행기맨이 어떤 *상황* 에서 어떤 mode 로 *드러나는지* 가 framework 의 *동작*.

## 5 mode

### 1. 재배맨 (Seedman) — 발아 mode

```
positive cover (씨앗을 심고 자라게 함)
```

비행기맨이 *agent 들을 출격시킬 때* 의 mode. n-ary dispatch substrate.

- 사용자 발화: "분석해줘 / 만들어줘 / 찾아줘"
- 비행기맨의 응답 mode: **재배맨** (parent process 가 4-phase 책임)
- 결과: subagent 출격 + 결과 수확 + KG write

본질: *작은 것을 심어 큰 것을 거두는* 양식. 시 측 "마음 약했던 물고기 친구들이 모여서" 모티프.

iter 7 Mirror verdict: **STRONG_OF_DIFFERENT_KIND** (cardinality 다르지만 mirror 성립 — different kind of mirror).

### 2. Prometheus — 지식 mode

```
knowledge-first (Hegel spiral)
```

비행기맨이 *모르는 것을 알아야 할 때* 의 mode. 외부 web search + KG pre-fetch + N parallel research + synthesis.

- 사용자 발화: "조사해줘 / 알아봐 / 찾아봐"
- 비행기맨의 응답 mode: **Prometheus** (9+1 cycle)
- 결과: ResearchFinding 수확 + UNWIND batch KG write + provenance

본질: *불(지식) 을 훔쳐 인간에게 가져다 주는* 양식. 그러나 *paralysis-by-analysis 회피* 정정 (2026-05-05) — hot-fix latency critical 시 KG-skip + immediate action 허용.

iter 7 Mirror verdict: **WEAK** (cardinality match 부족하지만 functional 측 valid).

### 3. Taliban — 적대 mode

```
negative cover (솎아내기)
```

비행기맨이 *나쁜 것을 찾아 제거할 때* 의 mode. GAN 측 discriminator. 적대적 검증.

- 사용자 발화: "이 코드 검토해줘 / 이 결정 비판해줘"
- 비행기맨의 응답 mode: **Taliban** (LensSet pluggable 적대적 검증)
- 결과: ValidationResult + USED_LENS edges + APPROVED/REJECTED verdict

본질: *솎아내는 자*. 시 측 "산소필멸자들에게 소닉붐 - 대나팔 초식을 시전" 측 *무자비한 자정* 모티프.

iter 7 Mirror verdict: **WEAK** (executor != reviewer 강제는 mirror condition 부분).

### 4. Longinus — 관통 mode

```
7-Layer Reference 관통 (KG ↔ code)
```

비행기맨이 *KG 의미층 과 코드 사이를 잇고자 할 때* 의 mode. 7-Layer reference + BX Lens + sha256 drift daemon.

- 사용자 발화: "이 코드 KG에 박아줘 / drift 검사해줘"
- 비행기맨의 응답 mode: **Longinus** (`# KG: lesson-xxx` 측 7-tuple 박기)
- 결과: ReferenceSite 노드 + drift detection + Reverse Orphan Scan

본질: *관통하는 창*. KG (天) 과 code (地) 사이의 *수직 piercing*.

iter 7 Mirror verdict: **STRONG_HIERARCHICAL** (7-layer 가 family expansion 측 hierarchical mirror 만족).

### 5. Harness — 자기참조 mode

```
self-reference (의도적 비움)
```

비행기맨이 *자기 자신을 보는* mode. industry agent scaffolding 측 4축 + 3-tier. 이 mode 는 *명시적으로 비어있다* — 자기 자신을 본다는 행위 자체가 mode 의 본질.

- 사용자 발화: "/harness <framework>" — 외부 framework 진단
- 비행기맨의 응답 mode: **Harness** (4축 모델 + 3-tier 적용 진단)
- 결과: 외부 framework 가 비행기맨 family 어디 위치하는지 + 어느 축 실패하는지

본질: *비행기맨이 자기 자신을 *대상* 으로 본다*. 시 측 "비행기 탔으면 반드시 비행기모드로 transform" — 자기 형태 변환의 자기 인식.

iter 7 Mirror verdict: **STRONG (unique)** — Mirror STRONG 조건 만족하는 *유일* case (responsibility_split + cardinality match). [bhgman_tool 측 family-expansion.md](https://github.com/gj3447/bhgman_tool/blob/main/docs/02-concepts/family-expansion.md) 참고.

## 5 mode 합체가 ∀-cover 를 어떻게 만드는가

각 mode 는 ∀-cover 의 *부분* 만 cover. 합체 시 *universal*:

```
∀x:CHU 에 대해, x 의 status 에 따라 mode 결정:

  x 가 unknown          → Prometheus mode (지식 채집)
  x 가 known + 미실현    → 재배맨 mode (subagent 출격)
  x 가 실현 + 미검증     → Taliban mode (적대 검증)
  x 가 검증 + 미박힘     → Longinus mode (KG 박기)
  x 가 self-reference   → Harness mode (자기 진단)

mode 선택은 *상황* 이 결정. 비행기맨은 *모든 상황에 응답할 수 있다*.
```

이 mode 분기 자체가 `∀x:CHU, j.covers x` 의 *engineering 측 실현*. 단일 행위자가 5 가지 *modus operandi* 를 가지므로 universal coverage.

## 시 측 5 mode 흔적

각 mode 가 시 측 어디에 흔적이 있는가:

| 모드 | 시 측 흔적 |
|---|---|
| 재배맨 (positive cover) | "마음 약했던 물고기 친구들이 모여서 / 나의 진실한 속마음 이야기를 들어주었습니다" — 작은 단위(물고기)의 *발아적* 모임 |
| Prometheus (지식) | "눈물을 머금고 하늘을 올려다보니 / 햇빛에 가려진 흑암의 존재가 보이는데" — *바깥(하늘)에서 새 지식이 들어옴* |
| Taliban (negative cover) | "산소필멸자들에게 소닉붐 - 대나팔 초식 / 폭풍우를 다시 소환해 버렸고" — *무자비한 솎아내기* |
| Longinus (관통) | "성층권한계돌파 / CLOUD CONNECT" — 두 층 (대지/하늘, code/KG) 사이 *piercing* |
| Harness (자기참조) | "비행기 탔으면 반드시 비행기모드로 transform 형상변환" — *자기 형태의 자기 인식* |

→ 시는 5 mode 의 동시 발현을 이미 *살고* 있다. 형식은 *후행* 인식.

family-relation-mirror-hypothesis (PROM 32 검증, 2026-04-30) 결과 비행기맨 (#4) 만이 STRONG Mirror 만족. 나머지 11 사도는 cardinality mismatch 또는 sub-type 이질.
